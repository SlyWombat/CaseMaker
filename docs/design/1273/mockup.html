#1273 step 2 — the mock-up, before any page code. For 9b. The rule as written on the issue: nothing recorded is not “a vise”; the Holding step asks, the way the Stock step does (#1263); every mount the product knows is listed, none preselected, an operator’s own pick allowed and marked as assumed; no jaws over the blank in the Stock step.
  • Which rows can be picked with no machine (from mountOptions’s needs): the three vise seats need only the blank, so they are selectable (each marked “not recorded for this shop”). The two bed rows need the bed’s size and its pins (bedTapeHold and bedBracketHold read the bed profile) and the rotary row needs the rotary’s envelope — all three come from a recorded machine, so they are listed but not selectable, with that reason.
  • The ask is one block at the top (amber, the Stock step’s own look). A: “No machine is recorded for this shop yet.” with the primary action Add the machine (Manage › Machines, returning to this step). C, a machine recorded with no bed profile (the same machineNow === null branch): “The machine is recorded, but its bed is not described yet.” with Describe the bed.
  • B: the operator’s own pick is stated for what it is — the job carries that hold with its source as the operator’s assumption; the existing “shipped dimensions, not measured on this machine” warning stands on the sheet; one line says the fit cannot be checked until the machine is recorded. Create the job is live.
  • D: the Stock step draws the blank plain when nothing is recorded (viseOnPins false there); the jaw-top reading it feeds is not shown.
  • Numbers in the frames are illustrative. Frames are drawn for desktop and phone width.
