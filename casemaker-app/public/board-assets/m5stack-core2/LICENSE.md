## Why

M5Stack publishes real geometry for the Core2 in their own hardware repository, and the repository carries an MIT licence at its root — the permissive grant covers modification and redistribution, so converting the STL to a GLB is allowed. This is the one board of the twelve with a manufacturer-published model *and* an unambiguous licence for it.

One caveat recorded honestly: the repository README does not name the `Structures/` files specifically, so coverage rests on the repo-root licence rather than a per-directory notice — normal for a hardware repo, but stated here so it is not mistaken for an explicit per-file grant.

M5Stack's **store** terms of service are a different surface and are restrictive (no copying site content "without express written permission"), so product photography from the shop is *not* covered by this clearance — the STL is the asset.
